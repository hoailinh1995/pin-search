Personal Pin Search – Privacy Policy

Last updated: November 1, 2026

Personal Pin Search is a personal, non-commercial tool built and used only by its developer (Pinterest account: linhtrnghoi). It lets the developer search and filter Pins saved on their own Pinterest boards using Claude Desktop through a locally running MCP server.

Data we access

With the account owner's OAuth consent, the app reads the owner's own boards and Pins (titles, descriptions, links and image URLs) through the official Pinterest API. Requested scopes are read-only: boards:read, pins:read and, optionally, boards:read_secret, pins:read_secret.

How data is used

Data is used only to answer the account owner's own search requests on their own computer. To do this, Pin metadata and images the owner asks about are passed to Claude (Anthropic's AI assistant), which processes them under the owner's own Claude account. The app does not create, edit or delete Pins or boards.

Storage

The app has no backend server. The OAuth access token is stored locally on the owner's computer and is never shared. Pinterest data is not stored server-side, sold, or shared with third parties, and is not used to train machine learning models.

Other users

The app is not offered to other users and does not collect data about any other Pinterest user.

Revoking access

Access can be revoked at any time in Pinterest settings under connected apps, after which the local token is deleted.
